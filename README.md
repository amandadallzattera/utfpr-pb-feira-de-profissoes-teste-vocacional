# UTFPR Vocacional Express

Crie um aplicativo web mobile-first para o Teste Vocacional da Feira de Profissões da UTFPR. Cores principais: Amarelo e Preto. A tela inicial deve ter um formulário coletando E-mail e um checkbox obrigatório de 'Consentimento LGPD'. Após o aceite, exiba um teste vocacional simples de 4 perguntas. No final, mostre uma tela de resultado. Deixe a estrutura pronta para eu conectar ao Supabase.
